Что внутри

Библиотека с обложками

Добавление .exe перетаскиванием, поиск, избранное, время в игре, сортировки.

Загрузки с докачкой

Ссылки, magnet и .torrent. Пауза, очередь, продолжение после перезапуска.

Каталог

Трей и автозапуск

Сворачивается в трей, загрузки продолжают идти. Автозапуск с Windows.

Установка

  1. Скачай установщик кнопкой выше.
  2. Запусти файл. Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить всё равно»: файл не подписан сертификатом.
  3. Выбери «Только для меня» — права администратора не нужны.
  4. Готово: ярлык появится в меню Пуск.

Данные хранятся в %APPDATA%\AmericaLauncher, загрузки — рядом с программой в папке downloads.

Частые вопросы

Нужен ли Python?

Нет. Python, Qt и libtorrent уже внутри установщика.

Почему антивирус ругается?

Сборки на PyInstaller иногда попадают под эвристику, а файл не подписан цифровым сертификатом. Можно добавить папку в исключения.

Есть ли игры внутри?

Нет. Лаунчер — библиотека и загрузчик. Каталог ведёт только на официальные источники: Steam, Epic, сайты разработчиков, Internet Archive.

Где посмотреть статистику?

Посещения считает Яндекс.Метрика, скачивания — GitHub Releases (счётчик подтягивается на эту страницу автоматически).
